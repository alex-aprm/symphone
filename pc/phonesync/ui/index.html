Install Symphone on your phone

Scan this code with your phone's camera to download the app. Open the downloaded file and allow installing it — Android asks once whether your browser may install apps.


Have a USB cable?

Turn on USB debugging on the phone (Settings › About phone › tap Build number 7 times, then Settings › Developer options › USB debugging) and plug it in. Symphone installs and sets up the app by itself — no tapping through permission screens.



Connect your phone

Open Symphone on your phone and tap Scan QR code — or scan it with the camera app.



Pair with the 6-digit code instead

Permissions on the phone

The Symphone app on your phone walks you through these — each one is explained there, and where Android can't ask directly it opens the right settings screen. This list updates live.

App windows while the phone is locked optional extra

Everything in Symphone works with the permissions you just gave the phone app — including the phone's screen on the PC (the phone asks to allow screen casting) and typing with the PC keyboard. One extra needs Android's wireless debugging: phone apps in their own PC windows while the phone stays locked in your pocket (plus call audio on the PC). Skip this if you don't need it; you can set it up later.



  1. On the phone: Settings › About phone, tap Build number 7 times
  2. Settings › Developer options › Wireless debugging → turn it on
  3. Tap Pair device with QR code and scan this code
  4. Waiting for the phone…

Extras for this PC optional

These need administrator rights; Windows asks once. You can add them later in Settings.

You're all set

Your phone reconnects by itself whenever it is nearby. A few things to try:

  • Apps — open any phone app in its own window, even with the phone locked
  • Status — notifications you can reply to, quick settings, calls
  • Right-click a file in Explorer → Send to → your phone
  • Copy on one device, paste on the other
